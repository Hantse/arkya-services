# Référence validée — arbres peints V3

« J'adore, faut ça comme référence pour les autres objets ».

objets d'environnement d'Arkya.

Ces copies figées proviennent de la [passe V3](../../../arbre-de-base/declinaisons/matieres-v3/README.md).

incorporées aux fichiers Blender et GLB.
