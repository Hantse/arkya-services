La page officielle autorise l'usage commercial, les modifications de couleur,
la réduction de polygones, le remplacement du rig et la redistribution des
fichiers modifiés. L'attribution doit rester accessible avec les dérivés.
Bake3D décrit cette source comme un modèle généré à partir d'une image.

Modifications Arkya : axes et échelle normalisés ; anatomie du loup dérivée du
renard ; articulations des membres et oreilles replacées ; poids de déformation
adaptés ; nombre de triangles réduit. Les UV et la peinture source sont
conservés. Les nouvelles couleurs, animations et marques magiques sont des
modifications Arkya. Aucune approbation d'Arkya par Bake3D n'est suggérée.
