## Inspection de la source

Ouverture dans Blender 4.5.14 avec exécution des scripts désactivée :
un maillage de **2 923 sommets et 5 358 triangles**, un atlas UV, un squelette
de **36 os** et les pondérations existantes. Aucune action d'animation n'est
présente. Le fichier couleur fait 1024 × 1024 pixels. Les cartes couleur,
normales, rugosité et spéculaire sont conservées telles quelles.

## Adaptation Arkya prévue — fichiers dérivés uniquement

La V4 repart de ce loup, distinct du renard Bake3D. L'adaptation prévoit de
normaliser axes et échelle, retravailler les mèches frontales et le regard,
abaisser le port de la queue, préparer le rig de présentation, puis appliquer
les douze pelages peints, les flux magiques et les animations Arkya.
Cette liste décrit l'intention de la reconstruction et ne constitue pas un
rapport d'export ou de validation. Les changements réellement livrés sont
documentés dans le README des totems et les rapports des assets dérivés.
